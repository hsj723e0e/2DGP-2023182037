소닉 애니메이션 뷰어 작성

개발언어 python
라이브러리 pico2d
파일이름: sonic_animation_viewer.py
단일 파일로만 작성.
스프라이트 이미지 sonic-sprite.png

기능
이미지의 모든 동작을 재생.
동작별 5회 재생, 1초 쉬고, 그 다음 동작 재생.
모든 동작을 다 재생한 후, 다시 무한 반복

추가 요구사항:
걷기, 달리기, 구르기처럼 이동이 포함된 동작은 프레임 재생과 함께 화면 위치도 이동.
화면 경계에서는 방향을 바꾸고 좌우 반전하여 이동.
동작별 1초 정지 중에는 마지막 프레임과 위치를 유지.

화면 대비, 이미지가 잘 보이게 충분히 확대
화면 배경은 검은색으로 표시.

개발 방법:
한번에 다 개발하지 말고, 단계별로 구현해서, 커밋을 그때 그때
할 수 있도록.
최소한 개발단계는 20단계 이상을 한다!!!
